How the value is fitted

What validation chose

Five variants were fitted in log space on the same 90 trading protocols, and one baseline in the style of the previous round — a median peer multiple, shrunk to the global median — was scored on the same 90 protocols and the same walk-forward split, so the comparison is apple-to-apple. Leave-one-out picks the winner; walk-forward is the number this board reports. The table is the ablation: each row is a variant, and the winner is the one the leave-one-out score picked, not the one with the most features.
